1. INTRODUCTION :

--> Trivial File Transfer Protocol (TFTP) is a simple file transfer protocol used to transfer files between a client and server over a network. It operates on UDP (User Datagram Protocol) and uses port 69 by default.

--> Unlike FTP, TFTP does not provide authentication or directory listing features. It is mainly used in embedded systems, routers, and network booting environments.

--> In this project, we implement a TFTP Client and Server in C using Linux system calls and socket programming.

4. ARCHITECTURE :

        +-------------+
        |   Client    |
        +-------------+
               |
               |  RRQ / WRQ
               |
               v
        +-------------+
        |   Server    |
        +-------------+
               |
               | DATA / ACK
               |
               v
        File Transfer

The communication occurs using UDP datagrams.




5. TFTP PACKET STRUCTURE :

Each TFTP packet contains:

                                Field	                        Size

                                Opcode	                        2 Bytes
                                Block Number	                2 Bytes
                                Data	                        512 Bytes

                                Maximum packet size:

                                2 bytes opcode
                                2 bytes block number
                                512 bytes data
                                -----------------
                                516 bytes




6. TFTP OPERATIONS ::
 
1. Read Request (RRQ)

-->> Client requests file from server.

-->> Client → RRQ → Server
-->> Server → DATA → Client
-->> Client → ACK → Server

2. Write Request (WRQ)

-->> Client sends file to server.

-->> Client → WRQ → Server
-->> Server → ACK → Client
-->> Client → DATA → Server
-->> Server → ACK → Client

8. SYSTEM CALLS :

-->> Creates communication endpoint.

        socket(AF_INET, SOCK_DGRAM, 0);
        bind()

-->> Binds socket to port.

        bind(sockfd, (struct sockaddr *)&server_addr, sizeof(server_addr));
        sendto()

-->> Sends UDP packet.

        sendto(sockfd, buffer, size, 0, addr, addrlen);
        recvfrom()

-->> Receives UDP packet.

        recvfrom(sockfd, buffer, size, 0, addr, addrlen);
        open()

-->> Opens file.

        open(filename, O_RDONLY);
        read()

-->> Reads file data.

        read(fd, buffer, size);
        write()

-->> Writes data to file.

        write(fd, buffer, size);





9. ALGORITHM :

--> Server Algorithm

--> Create UDP socket

--> Bind socket to port

--> Wait for client request

--> Receive RRQ or WRQ packet

--> If RRQ → send file

--> If WRQ → receive file

--> Send ACK packets

--> Repeat until transfer completes

--> Client Algorithm

--> Start client

--> Connect to server

--> Enter command

--> If GET → send RRQ

--> If PUT → send WRQ

--> Transfer file using DATA and ACK packets

--> Stop when file transfer completes
